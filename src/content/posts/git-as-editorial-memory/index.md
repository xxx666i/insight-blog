把文章放进 Git 后，版本记录不再只是技术备份。一次改标题、一次删除冗余段落、一次重新组织论证，都能成为写作过程的注脚。

## 提交信息写给未来的自己

好的提交信息不需要很长，但应该说明这次调整解决了什么问题。几个月后回看时，这些短句会比文件修改时间更有意义。

## 保留可以追溯的选择

并不是每一次改动都需要公开，但每一次重要取舍都值得被保存。写作因此从一次性发布，变成可以持续维护的长期作品。
