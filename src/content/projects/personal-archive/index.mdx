## 背景

这个项目要解决的不是“做一张好看的主页”，而是建立一个可持续维护的写作系统。内容需要通过 Git 管理，同时保持静态网站的可靠、快速与可迁移。

## 关键决定

- 使用 Astro Content Collections 验证文章、随记和项目的数据；
- 用温暖纸面、宋体长文和克制的梅子色建立统一视觉；
- 不加入评论、访问量和社交分享墙，让内容本身成为重心；
- 生产分支更新后，由 GitHub Actions 自动部署到 GitHub Pages。

## 当前状态

基础内容模型、主题、搜索、归档和阅读布局已经形成。后续工作主要是替换示例内容、加入真实头像与可公开的联系入口，并持续验证长期写作是否顺手。
